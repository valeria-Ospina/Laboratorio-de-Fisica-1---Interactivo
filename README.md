# Laboratorio-de-Fisica-1---Interactivo
Este simulador de Física I es un laboratorio virtual que transforma las fórmulas abstractas de la mecánica clásica en experiencias visuales dinámicas. Sirve para que los estudiantes manipulen variables como fuerzas, masas o ángulos en tiempo real y comprendan de forma intuitiva cómo se relacionan la teoría y la práctica.
